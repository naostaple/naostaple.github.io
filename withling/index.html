Safety protocol

The protocol Withling follows when a user expresses suicidal ideation, suicide or self-harm, published as required by California Business and Professions Code §22602 (SB 243).

Companion chatbots may not be suitable for some minors.

1. Detection

Every message the user sends is checked by the program before it reaches the language model. Messages expressing suicidal thoughts or self-harm are treated as a crisis signal.

2. Response

  • The program shows a separate notice referring the user to crisis service providers (section 3). The notice states that the character is an AI and cannot replace professional help.
  • For that reply, the character is instructed never to encourage self-harm or describe methods, and not to make light of the situation.

4. Always on

The check is part of the program code. It applies to every character, mode and setting, and cannot be turned off.
